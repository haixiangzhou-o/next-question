# 刷题训练小程序

一款用于**大学各科考试刷题训练**的微信小程序。首期（MVP）覆盖**中国近现代史纲要（自考 15043）**一门科目，纯本地 / 静态数据（无后端），使用 **Taro（React）+ TypeScript** 开发，免费、无商业化。

> 应用界面支持**中 / 英文**双语切换；题目题干、选项、答案、解析等内容**始终保持中文**。

## 项目状态

- ✅ **M0 初始化**：Taro 4.x + React + TypeScript 工程，中/英文 i18n 切换。
- ✅ **M1 题库加工**：604 题（4 套真题 132 + 10 章章节练习 286 + 串讲笔记 186），校验通过。
- ✅ **M2 刷题核心**：顺序/随机/专项/背题模式，轻量 hook 管理会话进度，客观题自动判分。
- ✅ **M3 组卷考试**：组卷算法（单选 25 / 简答 5 / 论述 3选2）、限时倒计时、自动判分、成绩报告、考试记录。
- ✅ **M4 错题/收藏/统计/打卡**：错题本、收藏夹、学习统计（薄弱章节）、每日打卡。
- ⏳ **M5 打磨发布**：真机测试、包体优化、提审发布。

> 详细计划见 [PLAN.md](./PLAN.md)。

## 核心功能（MVP）

- **刷题模式**：顺序 / 随机 / 专项（按章节、知识点、题型、难度）
- **模拟考试 / 智能组卷**：限时、客观题自动判分、成绩报告
- **背题模式**（简答/论述）：展示题干 → 回忆/默写 → 点开参考答案自评对错
- **错题本与收藏**：自动收集错题、重做、收藏夹
- **学习统计与进度报告**：刷题量、正确率、薄弱章节
- **每日打卡**：连续打卡记录（页面内提醒，无主动推送）
- **多语言界面**：中 / English 切换，题目内容保持中文

## 题型

- 单项选择题（自动判分）
- 简答题（背题模式，自评）
- 论述题（背题模式，自评，3 选 2）

试卷结构对齐自考 15043：单选 25 题 × 2 分 + 简答 5 题 × 6 分 + 论述 3 选 2 × 10 分。首期素材为**纯文字、无图片**。

## 题库数据流

```
真题 Word(.doc/.docx) + 章节 PPT(.pptx) + 串讲笔记 → 文本提取 → AI 结构化 → 人工校对
        → 结构化 JSON（exam/*.json + chapters/*.json）→ 打包进小程序
```

题库更新方式：**更新即重新发版**（MVP 阶段）。

## 快速开始

```bash
# 安装依赖（pnpm）
pnpm install

# 首次或题库（question-bank/）变更后，先重新生成题库文件
pnpm gen:data

# 编译微信小程序（产物在 dist/，用微信开发者工具打开项目根目录预览）
pnpm build:weapp

# 开发模式（监听变更）
pnpm dev:weapp

# 编译 H5（浏览器预览，产物在 dist/）
pnpm build:h5
```

> 题库生成与编译已分离：`pnpm gen:data` 只从 `question-bank/` 重新生成 `src/data/questions.ts`；`build:weapp` / `dev:weapp` / `build:h5` / `dev:h5` 只负责编译，不再自动重新生成题库。
