# 刷题训练小程序

一款用于**大学各科考试刷题训练**的微信小程序。首期（MVP）覆盖**中国近现代史纲要（自考 15043）**一门科目，纯本地 / 静态数据（无后端），使用 **Taro（React）+ TypeScript** 开发，免费、无商业化。

> 应用界面支持**中 / 英文**双语切换；题目题干、选项、答案、解析等内容**始终保持中文**。

## 项目状态

🚧 计划阶段 —— 详见 [PLAN.md](./PLAN.md)，尚未开始编码。

## 核心功能（MVP）

- **刷题模式**：顺序 / 随机 / 专项（按章节、知识点、题型、难度）
- **模拟考试 / 智能组卷**：限时、客观题自动判分、成绩报告
- **背题模式**（简答/论述）：展示题干 → 回忆/默写 → 点开参考答案自评对错
- **错题本与收藏**：自动收集错题、重做、收藏夹
- **学习统计与进度报告**：刷题量、正确率、薄弱章节
- **每日打卡**：连续打卡记录（页面内提醒，无主动推送）
- **多语言界面**：中 / English 切换，题目内容保持中文

## 技术栈

| 类别 | 选型 |

| 框架 | Taro 3.x + React + TypeScript |
| 后端 | 无（MVP 纯本地）；二期接入微信云开发 |

| UI | Taro UI / NutUI（React）或自写组件 |
| 国际化 | taro-i18n / react-i18next 适配 |

## 题型

- 单项选择题（自动判分）
- 简答题（背题模式，自评）
- 论述题（背题模式，自评，3 选 2）

试卷结构对齐自考 15043：单选 25 题 × 2 分 + 简答 5 题 × 6 分 + 论述 3 选 2 × 10 分。首期素材为**纯文字、无图片**。

## 题库数据流

```
真题 Word(.doc/.docx) + 章节 PPT(.pptx) + 串讲笔记 → 文本提取 → AI 结构化 → 人工校对
        → 结构化 JSON（exam/*.json + chapters/*.json）→ 打包进小程序
```

题库更新方式：**更新即重新发版**（MVP 阶段）。

## 目录结构（规划）

```
next-question/
├─ PLAN.md                    # 项目计划
├─ README.md                  # 本文件
├─ raw_materials/             # 原始资料（真题 Word、章节 PPT、笔记）
├─ tools/                     # 题库加工与校验脚本（Python + Node.js）
│  ├─ extract/                # Word/PPT 文本提取
│  ├─ structure/              # AI 结构化
│  ├─ validate/               # 校验脚本
│  └─ generate/               # 生成 exam/*.json 与 chapters/*.json
├─ question-bank/             # 结构化题库源数据
│  ├─ exam/                   # 真题集（2410/2504/2510/2604.json）
│  ├─ chapters/               # 章节练习（chapter-01 ~ chapter-10.json）
│  └─ notes/                  # 考点辅助（review-notes.json，可选）
├─ src/                       # Taro 应用源码
│  ├─ pages/                  # 页面
│  ├─ components/             # 通用组件
│  ├─ store/                  # 状态管理
│  ├─ repositories/           # 数据访问抽象层
│  ├─ services/               # 组卷、判分等纯逻辑
│  ├─ locales/                # 多语言资源（zh-CN / en-US）
│  └─ data/                   # 打包进小程序的题库
└─ config/                    # 构建配置
```
